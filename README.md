# INDIVIDUAL ASSIGNMENT

Each student should copy these files into the Week 3 QA System that they personally built and run all tests against their own implementation. All test cases, outputs, screenshots, analysis, and reflections must come from the student’s own chatbot.

# Lab 4 Starter Files – AI-Assisted Testing of a RAG Q&A System

1. Copy these files into your existing Week 3 QA System folder.
2. Edit **test_adapter.py** so `ask_chatbot(question)` calls your existing RAG pipeline.
3. Edit **test_cases.json** using facts from your own source documents.
4. Install pytest: `pip install pytest`
5. Run: `pytest -v`
6. Run: `python performance_test.py`
7. Run: `python stress_test.py`

The starter tests are intentionally generic. Adapt them to your system and requirements.
